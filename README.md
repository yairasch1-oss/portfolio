# yairaschresnick.com: אתר אנגלי + אתר עברי עם דשבורד

## מה יש כאן
```
content/projects/   ← פרויקט = קובץ אחד (כותרות, טקסטים ותמונות בשתי השפות)
content/site.json   ← שם, אודות, קורות חיים, פרטי קשר
media/              ← התמונות שתעלה מהדשבורד
styles/en.css       ← העיצוב של האתר האנגלי
styles/he.css       ← העיצוב של האתר העברי (עצמאי לגמרי)
.pages.yml          ← הגדרות הדשבורד
build.py            ← בונה את שני האתרים לתוך dist/en ו-dist/he
```
את התוכן עורכים בדשבורד. את העיצוב עורכים ב-CSS: `styles/he.css` משפיע רק על העברית.

**לצפייה מקומית:** פותחים `dist/he/index.html` בדפדפן. אחרי שינוי ב-CSS מריצים `python3 build.py`, או פשוט שומרים ב-GitHub ונותנים לאתר להתעדכן.

## הקמה (פעם אחת, הכל בחינם)

**1. GitHub: המקום שבו הקבצים יושבים**
- פותחים חשבון ב-github.com, יוצרים repository חדש (למשל `portfolio`), ומעלים אליו את כל התוכן של התיקייה הזו (Add file ← Upload files).

**2. אחסון: שני אתרים מאותו repository**
ב-Cloudflare Pages (או Netlify) מחברים את ה-repository ויוצרים שני פרויקטים:

| | אתר אנגלי | אתר עברי |
|---|---|---|
| Build command | `python3 build.py` | `python3 build.py` |
| Output folder | `dist/en` | `dist/he` |
| Custom domain | `www.yairaschresnick.com` | `he.yairaschresnick.com` |

מעכשיו כל שינוי שנשמר ב-GitHub מעדכן את שני האתרים לבד, תוך דקה-שתיים.

**3. הדשבורד**
- נכנסים ל-app.pagescms.org, מתחברים עם GitHub ובוחרים את ה-repository.
- זהו. רואים ״פרויקטים״ ו״פרטי האתר״, מעלים תמונות, עורכים טקסט ולוחצים Save.

**4. הדומיין**
- ב-DNS של הדומיין (כרגע ב-Wix) מוסיפים CNAME עבור `www` ועבור `he`, לכתובות ששירות האחסון נותן.
- הדומיין הראשי בלי www: Wix לא מאפשרת להחליף nameservers. הכי פשוט להעביר את הדומיין ל-Cloudflare (חידוש במחיר עלות), ואז הכל מנוהל במקום אחד.
- מבטלים את ה-Premium ב-Wix רק אחרי ששני האתרים עובדים.

## לפני שמבטלים את Wix
התמונות הקיימות עדיין נטענות מהשרתים של Wix. מעלים את קובצי המקור דרך הדשבורד (שדות התמונה בכל פרויקט), ואותו דבר לגבי ה-PDF של קורות החיים.

## פרויקט חדש
בדשבורד: פרויקטים ← Add an entry. ממלאים כותרות, מעלים כריכה ותמונות, קובעים מספר בשדה ״סדר״ ושומרים. סימון ״טיוטה״ מסתיר פרויקט מהאתר בלי למחוק אותו.
